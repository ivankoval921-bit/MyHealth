# Моё здоровье (MyHealth) v1.0.3

Разработчик: **Volodymyr's Ilchenko**  
Репозиторий: `https://github.com/ivankoval921-bit/MyHealth`

Единый долговременный мобильный дневник здоровья для Android (Kotlin + Jetpack Compose). Объединяет симптомы и общее состояние, непрерывную голосовую диктовку с датчиками кармана/переворота, системный ИИ-разбор, историю хронических ощущений, замеры приборов (включая фото экрана тонометра), питание/привычки, погоду/давление, экстренный самоконтроль 112 и архив анализов.

## Основные возможности (v1.0.2)
1. Единый микрофон непрерывной диктовки (`RU / UK / DE`) с паузой/продолжением, встроенным значком в полях и автостопом по датчику приближения и гироскопу/акселерометру (при перевороте или в кармане).
2. Системный ИИ-разбор (`✨ ИИ-разбор всего`, Gemini `3.8-flash` Interactions API, `store=false`): связывает жалобы, питание, кофе/алкоголь, сон, погоду, замеры и историю.
3. Отличие повторяющихся хронических ощущений от острых «Красных флагов» + выявление нетипичных кардиопризнаков (давление ниже горла / под челюстью / в левой руке).
4. Проактивные шаги («Померяйте сейчас давление и пульс» + `📷 Фото тонометра` через ML Kit OCR / Gemini Vision).
5. Таймер самоконтроля (`1 / 3 / 5 мин`) с громкой тревогой (`60 с`), голосовой карточкой диспетчера `112` (`TTS DE / RU`) и опциональным авто-SMS близкому.
6. Профили семьи (`Имя`, `Год р.`, `Телефон`, `E-mail`, `Адрес`, хроника, лекарства, аллергии), чистый репозиторий без личных данных, ZIP-бэкап и встроенное автообновление из GitHub Releases.
