# Моё здоровье (MyHealth) v1.0.1

Разработчик: **Volodymyr's Ilchenko**  
Репозиторий: `https://github.com/ivankoval921-bit/MyHealth`

Единый долговременный мобильный дневник здоровья для Android (Kotlin + Jetpack Compose). Объединяет симптомы, системную историю хронических ощущений, замеры приборов (включая фото экрана тонометра), питание/привычки, погоду/давление, экстренный самоконтроль 112 и архив анализов в одной базе с разделением достоверности данных.

## Основные возможности (v1.0.1)
1. Голосовой (`RU / UK / DE`) и 2-таповый ввод состояния + наводящие уточняющие вопросы с учётом истории.
2. Различение повторяющихся хронических ощущений и острых «Красных флагов», выявление нетипичных кардиопризнаков (давление ниже горла / под челюстью / в левой руке).
3. Проактивные шаги («Померяйте сейчас давление и пульс» + `📷 Фото тонометра` через ML Kit OCR / Gemini Vision).
4. Таймер самоконтроля (`1 / 3 / 5 мин`) с громкой сиреной/вибрацией (`60 с` на отмену), голосовой карточкой диспетчера `112` (`TTS DE / RU`) и опциональным авто-SMS доверенному контакту.
5. Погода, перепады атмосферного давления за 6/24 ч и AQI через Open-Meteo (без ключа).
6. Интеграция Gemini (`gemini-3.8-flash`, Interactions API с `store=false` по отдельному согласию).
7. Сканер PDF и фото документов (`ML Kit OCR` + `PdfRenderer`) + многостраничный PDF-отчёт для врача (`RU / DE`).
8. Профили семьи, ZIP-бэкап и встроенное автообновление из GitHub Releases (`version.json` + уведомление + установка APK).
