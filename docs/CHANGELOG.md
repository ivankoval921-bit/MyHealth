# История изменений — Моё здоровье

## v1.0.3 (2026-11-17)
- **Тестовый аварийный вызов (модель 112) для проверки с родственниками:** любой пользователь может ввести произвольный тестовый номер в Карточке 112 или Профиле, запустить звонок с громкой связью и голосовой озвучкой модели 112 (DE/RU), либо прогнать тестовый таймер 10 с (безопасно, не набирает реальный 112).
- **Список экстренных родственников (БД v4):** добавление неограниченного числа контактов (жена, муж, брат, дети, племянницы и т.д.) с быстрым звонком, массовой рассылкой авто-SMS (если включено) и передачей координат GPS + ссылки Google Maps (`SMS+GPS` / «Поделиться GPS»).
- **Живое обновление GPS:** использование `LocationManager.getCurrentLocation` (API 30+) для точной геопозиции.

## v1.0.2 (2026-11-17)
- Непрерывная голосовая диктовка: единый микрофон с кнопками «Пауза» / «Продолжить» / «Завершить», встроенная кнопка микрофона в поле симптомов и в поиске по истории.
- Датчик защиты от лишней записи (`PocketOrientationGuard`): автостоп микрофона при перевороте телефона вверх ногами/экраном вниз (акселерометр + гироскоп) или при закрытии датчика приближения (телефон убран в карман); настройка в Профиле.
- Кнопка «✨ ИИ-разбор всего» и расширение контекста Gemini (учёт недавнего питания, кофе, лекарств, замеров, хроники и погоды).
- Доработка интерфейса по скриншотам: отделённая от кнопки профиля строка `Разраб.: Volodymyr's Ilchenko`, фильтры истории с переносом строк (`FlowRow`) и счётчиками, поля `Телефон` и `E-mail` в профиле (БД v3), компактная карта профиля с кнопкой «Сохранить» в заголовке.

## v1.0.1 (2026-11-17)
- Разработчик **Volodymyr's Ilchenko**, отображение версии программы в заголовке, разделе «О программе» и в PDF-отчёте.
- Исторический контекст при оценке «Красных флагов»: различение хронических повторяющихся ощущений (напр. холодный мизинец / онемение пальцев в истории) и острых тревожных состояний; выявление нетипичных кардиосимптомов (давление ниже горла / под челюстью / левая рука).
- Проактивные подсказки «Рекомендуемый шаг прямо сейчас» (`+ Ввести АД/пульс`, `📷 Фото тонометра` с ML Kit OCR и Gemini Vision).
- Таймер самоконтроля (`1 / 3 / 5 мин`), громкая тревога (`60 с`), голосовая карточка диспетчера `112` (`TextToSpeech DE / RU`), домашний адрес в профиле и опциональное авто-SMS доверенному контакту (`SEND_SMS`).
- Контракт `SensorBridge`, репозиторий `ivankoval921-bit/MyHealth`, CI-сборка и встроенное автообновление из GitHub Releases.

## v1.0.0 (2026-11-17)
- Реализован Этап 1 (MVP): SQLite-база с профилями семьи и журналом доступа, голосовой/2-таповый ввод, наводящие вопросы, скрининг «красных флагов» (`112`), Open-Meteo (давление/погода/AQI), корреляционный движок, ML Kit OCR + PdfRenderer, Gemini Interactions API (`gemini-3.8-flash`, `store=false`), PDF-выписка для врача (`RU / DE`), ZIP-бэкап.
