# Руководство пользователя — Моё здоровье v1.0.1

1. **Вкладка «Сегодня»:** нажмите `Надиктовать` (или введите текст / выберите тяжесть `1–10` и теги), затем `Сохранить в дневник`. Нажмите `Обновить` в карточке погоды для фиксации атмосферного давления и GPS.
2. **Подсказки «Рекомендуемый шаг прямо сейчас»:** если при головокружении, боли или давлении за последние 2 часа нет замера АД, приложение предложит ввести цифры или нажать `📷 Фото тонометра` — цифры экрана распознаются через OCR / Gemini и сохраняются как `[Мед. прибор]`.
3. **Таймер самоконтроля и карточка `112`:** нажмите `⏱ 1 м / 3 м / 5 м`, если чувствуете себя неважно. Если не нажать `Я в порядке`, через 60 секунд тревоги откроется голосовая карточка диспетчера `112` (`DE / RU`) с кнопкой `🔊 Озвучить` и (при включённом разрешении `SEND_SMS` в Профиле) уйдёт авто-SMS доверенному контакту с адресом и GPS.
4. **Вкладка «История»:** поиск и фильтр по всей хронике с пометками источников (`[Пользователь]`, `[Мед. прибор]`, `[Врач / Лаб.]`, `[ИИ-оценка]`).
5. **Вкладка «Тренды»:** расчёт временных закономерностей (с оговоркой «статистика ≠ диагноз»), динамика лабораторных маркеров и кнопка подготовки сводки перед визитом к врачу.
6. **Вкладка «Карта»:** импорт PDF/фото анализов и заключений (с ручной правкой распознанного) + кнопка создания PDF-выписки для врача (`RU` / `DE`).
7. **Вкладка «Профиль»:** сведения о разработчике (**Volodymyr's Ilchenko**), проверка и установка обновлений с GitHub, профили семьи, домашний адрес, доверенный контакт + переключатель авто-SMS, согласие и ключ Gemini API, ZIP-бэкап.
